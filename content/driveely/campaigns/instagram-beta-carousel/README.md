---

## 1. Concept créatif global

### Nom de campagne
**« Avant d’accepter »**

### Idée centrale
Le téléphone n’est plus l’outil qui *pousse* à accepter — c’est le cockpit qui *tranche* avant.

Storytelling en une ligne :

> Tu acceptes trop vite → le montant affiché ment → Driveely calcule le gain net → tu décides.

### Direction artistique
- Ancre : identité Driveely (charcoal, violet Y, typo clean) + codes Linear / Raycast / Apple
- Héros : **iPhone photoréaliste** au centre de chaque slide
- Peu de texte · hiérarchie forte · zéro emoji · zéro badges flottants · zéro fake urgency
- Pas de “cerveau AI” générique — seulement l’UI produit

### Psychologie (éthique)

| Slide | Levier | Intention |
|-------|--------|-----------|
| 01 | Reconnaissance / empathie | « C’est moi » |
| 02 | Loss aversion (honnête) | Voir l’argent qui part |
| 03 | Status quo bias named | Nommer le réflexe |
| 04 | Competence gap | Créer le *besoin* d’info |
| 05 | Curiosity + clarity | Produit = réponse |
| 06 | Fogg : action facile | 3 gestes = low friction |
| 07 | Preuve concrète | Competence / confiance |
| 08 | Autonomy + contrôle | L’IA conseille, toi décides |
| 09 | Soft commitment | Bêta = accès, pas piège |

**Interdit (appliqué) :** faux revenus, “gagne 2k€/mois”, seats fake, timers FOMO, confirmshaming.
