# Playbook — Pricing

Barre : clarté **Stripe** ; comparaison scannable ; 1 plan recommandé.

---

## Étapes

### 1. Besoin produit
- Plans, features différenciantes, annual/monthly
- Audience (SMB / pro / enterprise)
- CTA par plan (unique wording clair)

### 2. Références
1. **Mobbin** — pricing mobile si applicable
2. **Refero** — pricing pages SaaS
3. **Raylight** — direction art sobre
4. Gold : **Stripe** pricing clarity

### 3. Style
- 3 plans max idéalement ; 1 highlight
- Feature matrix lisible (pas 40 rows jargon)
- FAQ courte sous le fold

### 4. Composants
1. **21st.dev FIRST** — pricing tables / toggles
2. **shadcn** — Toggle, Accordion FAQ, Button
3. Pas de Spline

### 5. Audit
- Vercel Guidelines (si marketing page)
- Anti-slop (cards clones, gradients)
- Frontend Design pour hiérarchie prix

### 6. Optimize
- Mobile stack plans ; contraste prix ; accessibilité tableau
