# Playbook — Paywall

Barre : clarté offre App Store / Stripe Checkout — conversion sans manipulation visuelle cheap.

**Cross-link behavior :** si paywall d’app **productivity / focus / habit / screen-time / gamification** → charger `behavioral-psychology` (**Étape 0**) + playbook paywall psy `/Users/quentinbouyssou/.cursor/skills/behavioral-psychology/playbooks/paywall.md` **avant** UI. Respecter `ANTI_DARK_PATTERNS.md` (pas de fake urgency, traps, lying UX).

---

## Étapes

### 0. Behavior (si applicable)
- Valeur / aha avant ou adjacent au paywall
- Anchoring & scarcity **honnêtes** seulement
- Trial / renew / cancel / restore clairs

### 1. Besoin produit
- Plans, prix, période, trial, restore purchases (mobile)
- Objection principale à lever
- CTA unique (« Continuer », « Start trial »)

### 2. Références
1. **Mobbin** — paywalls top apps (priorité absolue)
2. **Refero** — pricing/paywall web
3. **Raylight** — mood minimal si brand
4. Gold : apps catégorie + **Stripe** clarity

### 3. Style
- 1 plan highlight max
- Bénéfices scannables (pas mur légal dans le hero paywall)
- Trust sobre (App Store, garantie) — pas badges flashy

### 4. Composants
1. **21st** — pricing cards / comparison **si** web
2. **shadcn** — Toggle billing, Dialog légal
3. iOS : contrôles natifs + HIG (pas cards web)

### 5. Audit
- Anti-slop (trop de CTAs, illustrations AI)
- Apple HIG si iOS
- Pro Max UX paywall
- Accessibilité prix (contraste, Dynamic Type)
- Anti dark patterns (behavior skill)

### 6. Optimize
- Friction : nombre de taps, clarté prix barré, accessibilité VoiceOver

---

## Do / Don’t

| Do | Don’t |
|----|-------|
| Prix et période évidents | Dark patterns agressifs |
| 1 highlight | 4 plans égaux qui crient |
| Exit / restore clairs | Piéger la fermeture |
| Behavior gate si habit/focus | Fake countdown / counters |
