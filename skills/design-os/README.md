## Démarrage agents

1. Si productivity / focus / habit / gamification / screen-time → charger **`behavioral-psychology` avant UX**.
2. Lire **[SKILL.md](SKILL.md)** en premier (toujours).
3. Suivre **[WORKFLOW.md](WORKFLOW.md)** (étape 0 si behavior, puis 1–6).
4. Ouvrir le playbook de surface dans **[PLAYBOOKS/](PLAYBOOKS/)**.
5. Consulter **[TOOLS.md](TOOLS.md)** pour le choix d’outil.
5. Avant ship : **[CHECKLIST_ANTI_SLOP.md](CHECKLIST_ANTI_SLOP.md)**.
6. Commande **Audit Design** → **[AUDIT_DESIGN.md](AUDIT_DESIGN.md)**.
