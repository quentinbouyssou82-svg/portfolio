## Canvas (remplir)

```
Comportement cible : ____________________

TRIGGER
  Externe : 
  Interne (visé) : 
  Éthique OK ? ☐

ACTION
  Étapes actuelles : 
  Friction (taps / charge) : 
  Ability fix : 

VARIABLE REWARD
  Type (tribe/hunt/self) : 
  Honnête ? ☐  Dosé ? ☐

INVESTMENT
  Qu’est-ce qui s’accumule ? 
  Améliore le prochain cycle ? ☐
  Portabilité / exit OK ? ☐
```

---

## Diagnostic rapide

| Symptôme | Phase faible |
|----------|--------------|
| Pas d’ouverture spontanée | Trigger interne absent |
| Drop avant valeur | Action trop dure |
| Ouvre puis s’ennuie | Reward plate / fake |
| Pas de retour J+1 | Investment faible |
| Retour anxieux / rage-quit | Reward / loss toxique |

---

## Règle

Une feature = **une** boucle Hooked claire. Pas quatre loops concurrentes sur le même écran.
