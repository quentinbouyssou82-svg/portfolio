# Exemples — bons patterns

Patterns éthiques à réutiliser (génériques, pas marque-spécifiques).

---

## Activation

- Première valeur en < 90 s (focus démarré, première tâche cochée)
- Permission demandée **au moment** où elle débloque l’action
- Skip onboarding non bloquant

## Habitude

- Widget / cue home = « obvious »
- Bouton unique « Start » (easy)
- Checkmark + durée réelle (satisfying)
- Miss hier → CTA « Reprendre » sans drama

## Motivation

- Goals édités par l’user (autonomie)
- Niveaux de difficulté choisis (compétence)
- Amis opt-in seulement (relatedness)

## Rétention

- Progress ring / score basé sur actions réelles
- Weekly reset leaderboard (évite domination permanente)
- Export données / pause mode

## Paywall

- Prix + période + renew sur la même vue
- Restore purchases visible
- Free tier utile (pas pure teaser vide)

## Focus / screen time

- Effort → unlock (delayed reward)
- Règles de strike **choisies** et affichées
- Stats calm, pas guilt quotidien
