# Driveely — notes comportementales (légères)

Contexte optionnel : app courier / livraison. **Notes**, pas playbook complet.

---

## Jobs typiques

- Accepter / enchaîner courses
- Naviguer sous stress temps
- Comprendre gains / pourboires
- Rester motivé sur créneaux longs

## Leviers utiles (éthiques)

| Levier | Application prudente |
|--------|----------------------|
| Clarity next action | Une course / un CTA dominant |
| Competence | Feedback livraison OK, stats réelles |
| Goal gradient | Proche de l’objectif de gains de shift |
| Autonomy | Filtres / pause / fin de shift clairs |
| Relatedness | Support / équipe — pas spam ranking humiliant |

## Risques spécifiques

- Gamifier la vitesse → sécurité (interdire incentives dangereux)
- Loss aversion sur « accept now or lose » agressif
- Notifs overload pendant conduite
- Opaque earnings = distrust

## Règle

Si feature engagement Driveely → Behavior Audit + prioriser **sécurité / clarté gains** avant gamification.
