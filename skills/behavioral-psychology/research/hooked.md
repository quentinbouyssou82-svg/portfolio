# Hooked — Nir Eyal

Source : *Hooked: How to Build Habit-Forming Products* (Nir Eyal, avec Ryan Hoover). Synthèse agent — **citer le modèle, ne pas inventer d’études**.

---

## Boucle (4 phases)

1. **Trigger** — externe (notif, email, UI) → interne (émotion, routine, ennui)
2. **Action** — comportement le plus simple vers la reward (ability ↑ + motivation ↑, B.J. Fogg)
3. **Variable Reward** — incertitude qui maintient la curiosité (tribes / hunt / self)
4. **Investment** — effort user qui charge le trigger suivant (data, contenu, réputation, skill)

Objectif produit éthique : habitude **au service** de l’utilisateur, pas captivité.

---

## Triggers

| Type | Exemples | Règle éthique |
|------|----------|---------------|
| Externe | Push, badge, email, deep link | Consent + utilité réelle |
| Interne | Ennui → ouvrir app ; anxiété → check score | Ne pas **créer** l’anxiété pour monétiser |

Passer d’externe → interne = signe d’habitude formée (Eyal).

---

## Action (Fogg × Hooked)

- Motivation × Ability × Prompt (Fogg Behavior Model)
- Réduire friction (taps, cognitive load) **sans** retirer le consentement
- Une action primaire par moment

---

## Variable rewards (3 types Eyal)

| Type | Idée | Exemple produit éthique |
|------|------|-------------------------|
| **Tribe** | Récompense sociale | Vrai classement amis, kudos |
| **Hunt** | Ressource / info | Découverte de tip utile, pas lootbox |
| **Self** | Maîtrise / compétence | Score de focus réel, streak soft |

Éviter : rewards décorrélées de la valeur (dopamine gratuite).

---

## Investment

- Stockage de valeur : préférences, historique, maîtrise, relations
- Doit **améliorer** le prochain cycle (meilleur trigger / reward)
- ≠ lock-in abusif (données otages, cancel impossible)
