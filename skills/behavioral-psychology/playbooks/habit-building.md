# Playbook — Habit building

Objectif : installer **une** habitude choisie. Clear 4 lois + Hooked investment.

---

## Étapes

1. Nommer l’habitude (verbe + contexte + fréquence)
2. Cue évident (widget, heure, stack)
3. Version 2 minutes (démarrage trivial)
4. Reward immédiat honnête
5. Investment (historique, identité)
6. Recovery « never miss twice »
7. Behavior Audit si critique

## Do / Don’t

| Do | Don’t |
|----|-------|
| Une habitude à la fois | 12 habits day 1 |
| Soft streak + grace | Shame reset |
| Identité | Goals abstraits seuls |
| Environnement / OS cues | Spam push |
