# Playbook — Productivity app

Objectif : aide à **faire le travail** — motivation compétence + friction basse.

**Règle DESIGN_OS :** charger `behavioral-psychology` **avant** toute proposition UX.

---

## Priorités psy

1. Clarity du next action (une chose)
2. Easy start (2-minute rule)
3. Progress visible (compétence)
4. Autonomy (listes / priorités user)
5. Rewards sobres (fin de tâche), pas confetti permanent
6. Retention via unfinished + habit cue — pas guilt

## Anti-patterns productivity

- Dashboard vanity metrics
- Gamification lourde sur to-do basique
- Over-notify « tu as 12 tâches »
- Infinite planning sans doing
