# Playbook — Retention

Objectif : raison de revenir J+1 / S+1 sans addiction forcée.

---

## Leviers rétention éthiques

| Levier | Comment |
|--------|---------|
| Habit cue | Rappel contextuel consent |
| Unfinished progress | Reprise facile (goal gradient) |
| Variable reward dosé | Contenu utile, pas casino |
| Investment | Data / maîtrise / relations portables |
| Social opt-in | Amis, défis choisis |
| Novelty bornée | Nouveaux défis sans overload |

## Diagnostic churn

- Pas d’aha → fixer onboarding
- Aha sans cue → habit design
- Cue sans value → core loop
- Value + shame → soft recovery
- Value + piège sub → trust break (churn latent)

## Métriques (si dispo)

Activation · D1/D7 · habit frequency · voluntary return (sans push) · cancel reasons
