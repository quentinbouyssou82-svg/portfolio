# Playbook — Focus app

Objectif : aider à **protéger l’attention** — reward après effort.

---

## Boucle cible

Trigger (intention) → Start focus (easy) → Session → Reward (crédits / check / insight) → Investment (score, historique)

## Leviers alignés

- Delayed gratification (Lembke)
- Commitment device (block apps / mode focus)
- Competence feedback (durée réelle, focus quality si honnête)
- Loss aversion soft sur « break rules » **si** règles choisies

## UX psy

- Start ≤ 2 taps
- Defaults sains (durée)
- Fin de session = peak-end clair (résumé)
- Interruptions : règles transparentes

## Interdits

- Gamifier le focus jusqu’à distraction
- Punition opaque
- Notifs qui cassent le focus pour « engager »
