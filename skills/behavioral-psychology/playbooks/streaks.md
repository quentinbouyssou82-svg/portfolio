# Playbook — Streaks

Objectif : consistance — **pas** peur.

---

## Design éthique

- Streak = feedback de régularité, pas otage émotionnel
- **Grace day / freeze / shield** (limités, clairs)
- « Never miss twice » (Clear) dans copy + UX
- Afficher la série **et** le total lifetime (réduit panique)
- Pas de notif shame (« tu as tout perdu »)

## Variantes

| Type | Usage |
|------|-------|
| Daily streak | Habits quotidiennes |
| Weekly consistency | % jours actifs (plus doux) |
| Chain soft | Miss = pause, pas zéro forcé |

## Interdits

- Reset total sans warning
- Streak payant pour « sauver » (loot shame)
- Leaderboard streak humiliant public forcé
