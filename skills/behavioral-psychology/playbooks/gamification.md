# Playbook — Gamification

Objectif : soutenir compétence / progression — pas décorer un vide.

---

## Process

1. Valider valeur core **sans** jeu
2. Motivation map (SDT)
3. Choisir **1–2** éléments (pas PBL complet d’un coup)
4. Lier rewards à actions réelles
5. Opt-in social / leaderboards
6. Audit anti-addiction (caps, pauses)
7. Behavior Audit

## Stack recommandé (éthique)

Progress visible → small badges de maîtrise → challenges opt-in → leaderboard amis

## Éviter

- Points pour tout
- Pay-to-win
- Lootboxes / gacha
- Fake progress bars
