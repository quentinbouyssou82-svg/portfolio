# Playbook — Screen time app

Objectif : réduire usage compulsif via friction + prise de conscience — **pas** moralisation toxique.

---

## Stratégie

1. Mesure honnête (baseline)
2. Framing compréhensible (temps / équivalents) — méthode visible
3. Limites & schedules (ability ↓ sur mauvaise habit)
4. Earn / unlock si modèle « effort → access »
5. Insights calm (pas guilt spam)
6. Off-ramps (pause app rules)

## Clear inverses

Invisible · Unattractive · Difficult · Unsatisfying appliqués aux apps distractives.

## Risques

- Shame spirals → churn ou mensonge à soi
- Sur-blocage → bypass / désinstall
- Paywall qui monétise la peur
